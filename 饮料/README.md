# 家庭自制饮料

这组饮料使用常见食材和普通厨房器具，每份约4杯；酸梅汤与雪梨饮可以分成4—5杯。糖量可以按口味减少或省略，成品量为估算，分杯时以实际做出的量为准。

## 菜谱选择

| 菜谱 | 总用时 | 约成品量 | 喝法 | 茶与奶 |
|---|---|---|---|---|
| [柠檬薄荷气泡水](柠檬薄荷气泡水.md) | 10—15分钟 | 1升，不含冰块 | 冷饮或室温 | 均不含 |
| [家常酸梅汤](家常酸梅汤.md) | 55—65分钟 | 过滤后1.2—1.4升 | 热饮或冷饮 | 均不含 |
| [冰糖雪梨饮](冰糖雪梨饮.md) | 35—40分钟 | 含梨块1.2—1.4升 | 热饮或冷饮 | 均不含 |
| [红茶鲜奶茶](红茶鲜奶茶.md) | 热饮15—20分钟；冷饮50—90分钟 | 约1升 | 热饮或冷饮 | 含红茶和牛奶 |
| [香蕉燕麦奶昔](香蕉燕麦奶昔.md) | 25—40分钟 | 约1升 | 冷饮或室温 | 含牛奶 |
| [鲜玉米牛奶饮](鲜玉米牛奶饮.md) | 40—55分钟；温热另加3—5分钟 | 1.1—1.2升 | 冷饮或温热 | 含牛奶 |

气泡水的预冷，以及酸梅汤、雪梨饮做成冷饮的冷却和冷藏时间另计。奶茶冷饮用时已包含降温与冷藏；奶昔和玉米饮用时包含燕麦或玉米的处理与降温，额外冷藏至冰凉仍需留时间。锅具、火力和室温会影响实际用时。

想快速做一壶，选气泡水；热饮可选鲜奶茶。燕麦已提前泡软并及时冷藏时，奶昔约5—8分钟可完成；已有煮熟、冷却的玉米粒时，玉米饮约8—10分钟可完成。

## 甜度与扩量

- 先用菜谱中的较低糖量，尝味后再少量增加。雪梨、香蕉和甜玉米本身有甜味，可以先不加糖。
- 想做6杯，基本用量乘1.5；想做8杯，乘2。具体扩量配方见各菜谱，烧水、冷却和分批搅打可能需要更久。
- 茶的浸泡时间不随杯数加倍，玉米仍要煮熟煮软。锅和搅拌杯容量不足时分批做，不超过器具标注的容量上限。
- 气泡水最后加入，轻轻拌匀；奶昔和玉米饮静置后可能分层，喝前搅匀。加冰会增加水量，酸甜度和奶味也会变淡。

## 卫生与存放

制作前洗手，清洗杯壶、滤网和搅拌杯；水果、薄荷用流动清水洗净，去皮前也先清洗。调饮用水和冰块使用可直接饮用的水，牛奶使用可直接饮用的成品，开封后按包装要求保存。[FoodSafety.gov 清洁食材与器具说明](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety)

热饮做成冷饮时，分装到干净的小份或浅容器中尽快冷却、冷藏，也可以用冰水浴辅助降温，外部的水不要进入饮料。玻璃等容器先确认耐热及是否允许急冷；不要把整锅饮料放在室温下一直等到彻底凉透。

含奶、切好的水果或煮熟食材的饮料及备料，暂时不饮用时及时放入4°C或以下的冰箱。易腐食物应在2小时内冷藏，环境温度高于32°C时缩短到1小时内。[FoodSafety.gov 冷藏与快速冷却说明](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety)

按当天饮用量制作，现调、现打的饮料尽量当天喝。需要留存时及时盖好冷藏，喝时取出所需份量；不把含奶饮料放在室温中过夜，也不反复温热整壶。

奶昔和玉米饮按普通搅拌机设计，熟食材先降温再搅打。想喝温热的玉米饮，打好后倒入小锅加热；机器能否处理热食材及装料上限，以说明书为准。
