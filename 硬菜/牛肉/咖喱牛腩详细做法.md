# 咖喱牛腩详细做法

这份家庭咖喱牛腩用咖喱块调味，搭配土豆、胡萝卜和洋葱，适合浇在米饭上吃。**先把牛腩炖至接近软烂，再煮熟蔬菜，最后加入咖喱块**，能减少土豆煮散和浓汁粘锅的问题。

- **份量：**约4人份配餐菜，米饭另备。
- **配方基准：**600克净牛腩，蔬菜按处理后的净重计。
- **总用时：**约2.5—3.5小时，其中实际动手约30—40分钟；牛腩软烂所需时间会有差别。
- **锅具：**约5升的厚底汤锅，焯水后洗净可继续使用。

## 一 食材准备

| 食材 | 用量 | 选择与用途 |
|---|---:|---|
| 牛腩 | 600克 | 选适合炖煮、略带筋的部位，修掉厚重外层肥油 |
| 土豆 | 400克 | 去皮后净重，切约2—3厘米的块 |
| 胡萝卜 | 200克 | 去皮后净重，切约1.5厘米的块 |
| 洋葱 | 200克 | 切小块，炒香后与牛肉同炖 |
| 生姜 | 10克 | 切片，与牛肉同炖 |
| 食用油 | 共15克 | 用于炒洋葱和牛肉 |
| 清水 | 先加1升，另备300—500毫升开水 | 前者炖牛肉，后者按蒸发情况补入；焯水另计 |
| 咖喱块 | 80—100克作为备料参考 | 选择用于咖喱饭的块状调味料，实际用量根据产品包装、汤量和咸淡调整 |
| 无糖椰浆 | 100毫升，可选 | 增加椰香，计入最后的液体量 |
| 盐 | 0—1克 | 咖喱块已经带咸味，最后尝味再决定是否需要 |

咖喱块的含盐量、浓度和建议水量随产品而异，按克称量并查看包装，不只数小块。咖喱粉与咖喱块的调味、增稠能力不同，替换时需要另外调整配方。

## 二 详细步骤

### 1 切牛腩并准备蔬菜

牛腩修掉多余肥油，切成约3厘米的块。洋葱和生姜先切好；土豆、胡萝卜可在牛腩炖煮期间处理。

土豆去皮切块后若暂时不下锅，可浸在清水中；等待较久时放冰箱冷藏，下锅前沥干。胡萝卜切块后也先冷藏，等需要时再取出。

### 2 冷水下锅焯牛腩

牛腩放进锅里，加冷水没过食材，开盖加热。出现浮沫后及时撇去，**从水沸腾后计时，继续焯约3—5分钟**。

捞出牛肉，用温水冲去附着的浮沫。倒掉焯水，把锅内沉渣洗净、擦干，再开始炒制。

### 3 炒香洋葱并开始炖牛肉

锅用中火温热，加入全部15克食用油，放入洋葱，炒约4—5分钟，至略透明、边缘开始微黄。

放入牛腩和姜片，翻炒约2分钟，加入1升清水。烧开后撇去新出现的浮沫，转小火，加盖并留小缝，让汤面保持轻微冒泡。

### 4 先把牛腩炖至接近软烂

先炖约90—120分钟，期间偶尔轻推锅底。汤汁下降太多时，每次补100—150毫升开水，让牛肉保持浸在汤中，锅内留出沸腾空间。

从炖满90分钟开始检查：筷子能较容易插进牛肉，咬起来已经明显变软、仅剩少许韧度，就可以放蔬菜。若还明显发硬，每次延长15—20分钟再检查，**不急着放土豆和咖喱块**。

### 5 加土豆和胡萝卜并调整汤量

加入沥干的土豆和胡萝卜，轻轻拌匀。重新煮开后转小火，再煮约20—30分钟，直到土豆和胡萝卜能轻松戳透、牛腩软烂。时间以食材软熟程度为准，中途避免用力搅碎土豆。

加咖喱前检查汤量：这份家庭配方可从约600—800毫升的汤液开始调整，汤中含有蔬菜析出的水，不要求精确量杯测量。汤太多时先开盖适当收浓，太少时补少量开水；另留一点流动性，后面咖喱块还会增稠。

如果加入100毫升椰浆，先倒入椰浆并重新煮开，椰浆也算入上面的液体量。所用咖喱块包装建议的水量明显不同时，按该产品说明调整汤量和调味用量，不把起始炖肉用的1升水当成必须保留的最终汤量。

### 6 关火溶解咖喱块

关火后，按产品包装建议取所需的咖喱块，掰成小块。先加入预计用量的约四分之三，用勺子轻推、搅至完全溶解，避免块状调味料沉在锅底。

重新开小火，保持轻微冒泡，煮约5—10分钟，期间经常沿锅底轻轻搅动。关火溶解、再小火搅拌煮浓的操作可参照[S&B 咖喱块烹调说明](https://www.sbfoods-worldwide.com/europe/golden-curry/recipe01/)和[好侍咖喱块烹调说明](https://housefoods-group.com/products/en/recipe/java.html)。牛腩的炖软时间按前面的步骤判断。

### 7 调整浓稠度和咸淡

咖喱汁能流动、又能薄薄裹住牛肉和蔬菜即可。太稠时，每次补30—50毫升开水，搅匀并重新煮开。太稀而咸淡仍偏轻时，可小火短时收汁；如果味道已经足够，可压碎两三块已熟的土豆拌入汁中，再短时煮匀，避免为了增稠不断加咖喱块。

如果味道仍淡，再把剩余咖喱块分次加入：每次先关火溶解，再小火煮开、搅匀尝味。确认咖喱已经充分溶解并煮浓后，才决定是否补少许盐，通常无需额外加盐。

盛盘时把牛肉和蔬菜均匀分成4份，浇在米饭上，或将米饭与咖喱分开盛。关火后咖喱还会略变稠，出锅时保留一点流动性更合适。

## 三 常见问题

| 问题 | 调整方法 |
|---|---|
| 牛腩硬、咬不动 | 先延长清汤炖肉的阶段，接近软烂后再加蔬菜；不靠固定分钟数判断所有牛腩。 |
| 土豆碎烂 | 土豆后放，切块保持大小一致，煮熟后轻推而不大力搅拌。 |
| 加咖喱后粘锅 | 咖喱块最后加入，先关火溶解，再小火煮；经常沿锅底搅动，太稠时少量补水。 |
| 咖喱太咸 | 停止加咖喱块和盐，少量补水稀释并煮热，之后不再明显收汁；下次按实际汤量减少咖喱块用量。 |
| 咖喱味淡但汁已很稠 | 先少量补水恢复流动性，再按需要补咖喱块并煮匀，避免直接在干稠锅底加块。 |
| 复热后太稠 | 先加少量水，小火搅拌加热；不要把冷的浓咖喱直接大火收干。 |

## 四 提前准备与扩量

可以前晚把整锅做好，或只把牛腩炖软，及时分装到浅容器中冷藏。易腐熟食一般应在2小时内冷藏，环境高于32°C时缩短到1小时内，冰箱保持4°C或以下。[FoodSafety.gov 熟食冷藏说明](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety)

再吃时取所需份量，加入少量水，小火边搅拌边充分复热，确认牛肉和土豆中心也热透；有温度计时，复热食品中心达到至少74°C。只提前炖好牛腩的，可在复热汤肉后接着煮蔬菜，再按步骤加入咖喱块。[FoodSafety.gov 熟食复热温度](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)

做6人份时，牛腩用900克、土豆600克、胡萝卜300克、洋葱300克、姜15克、油约22克，清水先加约1.5升，可选椰浆150毫升；咖喱块仍按实际汤量和包装说明分次调整。换用约7升的锅，牛肉与蔬菜保持原来的切块大小，烧开时间会增加，炖煮时间仍以软烂程度判断，不直接按人数相乘。
