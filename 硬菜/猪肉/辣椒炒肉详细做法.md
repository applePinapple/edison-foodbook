# 辣椒炒肉详细做法

这份家庭辣椒炒肉用前腿瘦肉搭配少量五花肉，辣椒有香味，肉片也能保持嫩口。**辣椒先干煸，五花肉煸出少量油，瘦肉炒熟后先盛出，最后一起回锅调味**，适合配米饭吃。

- **份量：**约3—4人份配餐菜。
- **配方基准：**400克净猪肉，其中前腿瘦肉300克、五花肉100克；搭配350克青辣椒。
- **总用时：**约25—30分钟，包含切配、腌肉和炒制；肉较多或火力较小时，分批炒并适当增加时间。
- **锅具：**30—32厘米的炒锅。干煸辣椒时使用适合干炒的锅具，锅先温热，不长时间空烧。

## 一 食材准备

| 食材 | 用量 | 选择与用途 |
|---|---:|---|
| 前腿瘦肉 | 300克 | 去掉粗筋，逆着纹理切约2—3毫米的薄片 |
| 五花肉 | 100克 | 去掉较硬的肉皮，切约2—3毫米的薄片 |
| 青辣椒 | 350克 | 螺丝椒、尖椒或青椒均可，按能接受的辣度选择 |
| 大蒜 | 15克 | 约4—5瓣，拍裂或切片 |
| 生姜 | 5克 | 切薄片或细丝 |
| 豆豉 | 8克，可选 | 增加香味，略切碎；豆豉本身有咸味 |
| 生抽 | 共20毫升 | 腌瘦肉用10毫升，最后回锅用10毫升 |
| 老抽 | 约3毫升，可选 | 最后回锅时少量上色 |
| 玉米淀粉 | 3克，可选 | 腌瘦肉时加入，薄薄挂浆即可 |
| 食用油 | 先准备15克 | 腌肉用5克、煸五花肉用5克，其余5克按锅内出油情况补，不必全用 |
| 盐 | 先准备1克 | 出锅前尝味再决定是否补加，生抽和豆豉已带咸味 |

辣椒的辣度因品种和批次而异。想减少辣味，可去掉部分籽和白色筋膜，或把一部分辣椒换成不辣的青椒；处理辣椒后及时洗手，避免揉眼睛。

## 二 详细步骤

### 1 切肉并处理辣椒

五花肉和瘦肉分开切片、分开放置，瘦肉逆纹切，厚度尽量一致。辣椒去蒂，按大小斜切成约3—4厘米的片；较大的青椒可以切成同样大小的块。

辣椒洗好后充分沥水、擦干表面，避免下锅时出水。蒜、姜和可选的豆豉备好，炒制开始后不再临时切配。

### 2 腌瘦肉

瘦肉加入10毫升生抽，抓拌均匀。使用淀粉时再加入3克淀粉，拌到肉片表面薄薄附着一层，最后拌入5克食用油。

腌约10分钟，等待期间放冰箱冷藏。五花肉暂时不加生抽，方便先煸油；腌瘦肉期间可以进行下一步。

### 3 干煸辣椒并盛出

锅中不加油，用中火温热锅后放入擦干的辣椒，勤翻动，干煸约3—5分钟。

辣椒略变软，表面开始起皱、有少量浅褐色斑点时盛出。不要一直大火烧到发黑；锅底变焦时先降低火力。辣椒此时不必完全炒软，最后还要回锅。

### 4 煸出五花肉的油

锅中加入5克食用油，放入五花肉，中小火翻炒约3—4分钟，至肉片熟透、边缘微黄，并煸出少量油。不要一直煎成干硬的肉渣。

把五花肉盛到干净盘中，锅内留一层薄油。若已经有明显油层，备用的5克油不用再加；出油太多时盛出一部分，避免成菜油腻。

### 5 分批炒瘦肉

调到中大火，放入腌好的瘦肉，迅速拨散并翻炒，避免肉片粘成一团。家庭灶火力不大时，300克瘦肉分成两批，每批约150克，前一批盛出后再炒后一批。

每批通常约需2—3分钟，肉片要炒熟再盛到干净盘中。时间随厚度、锅温和下锅量变化；有食物温度计时，可检查最厚处中心达到至少75°C，不能只凭表面变色判断熟度。[香港食物安全中心 烹调食物的熟度说明](https://www.cfs.gov.hk/english/consumer_zone/safefood_all/five_keys_reminder.html)

炒制时若锅底已经缺油、明显粘住，再从备用油中少量补加；有油膜时不用再补。

### 6 炒香蒜姜并一起回锅

转中火，利用锅内剩下的少量油，加入蒜、姜和可选的豆豉，炒约20—30秒，至香味出来，避免炒焦。

先把辣椒倒回锅中。若辣椒还偏硬，先单独炒到接近喜欢的软度，再放回五花肉和瘦肉。

加入剩余10毫升生抽及可选的老抽，转中大火快速翻炒约1—2分钟，让调味均匀附着，肉和辣椒一起热透，随即进入下一步，减少肉片反复受热。

### 7 尝味并出锅

尝一小块已经熟透的肉或辣椒，再决定是否从备用的1克盐中少量补加。生抽和豆豉已经够咸时，可以不再加盐。

炒到锅底没有明显积水、肉和辣椒裹上调味即可出锅。不要为了收汁一直炒肉；若锅内积水较多，先盛出熟肉，短时收干多余水分，再回锅拌匀。

## 三 常见问题

| 问题 | 调整方法 |
|---|---|
| 肉片柴、发硬 | 瘦肉逆纹切薄片，分批炒，熟透后先盛出；最后只短时间回锅。 |
| 肉片出水多 | 锅温不够或一次下肉太多，按约150克一批炒；不要额外往腌肉里倒很多水。 |
| 辣椒只有辣味、不香 | 先擦干，干煸到略起皱，再与肉回锅；避免直接在大量肉汁里焖煮。 |
| 太咸 | 生抽、豆豉与盐一起计入调味量，盐最后尝味再加，不叠加其他咸味酱料。 |
| 太油 | 五花肉出油后只留薄油层，备用油按需添加。 |

## 四 提前准备与扩量

可以提前切好肉和辣椒，分别密封冷藏；生肉与能直接食用的食物分开，炒熟后使用干净的盘子和餐具。这道菜当天现炒口感更好。需要留到下一顿时，及时分装冷藏，再吃时充分复热，避免反复冷却和加热。[香港食物安全中心 食物存放与复热说明](https://www.cfs.gov.hk/english/consumer_zone/safefood_all/five_keys_reminder.html)

做6人份配餐菜时，可将本配方按4人份计，食材乘1.5：瘦肉450克、五花肉150克、辣椒525克、蒜约22克、姜约8克、豆豉12克、生抽共30毫升，其他调味相应调整。盐仍先少放，油根据五花肉出油情况添加。

加量后保持肉片原来的厚度，瘦肉分成约150克一批炒，辣椒也可分批干煸；炒制时间会随批次数增加，不把全部食材一次倒进原锅。
