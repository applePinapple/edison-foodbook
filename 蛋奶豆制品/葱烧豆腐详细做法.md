# 葱烧豆腐详细做法

这份家庭葱烧豆腐用北豆腐和大葱，豆腐外层微黄，里面保持软嫩，汤汁带有葱香。**豆腐擦干后分批煎，葱白用中小火炒香，再加料汁烧入味，最后按需要薄薄勾芡**，适合配米饭吃。

- **份量：**约3—4人份配餐菜。
- **配方基准：**500克沥去包装水的北豆腐，搭配150克去根和老叶后的大葱。
- **总用时：**约35—40分钟，包含切配、分批煎豆腐和烧制。
- **锅具：**28—30厘米的不粘平底锅或适合煎豆腐的炒锅、宽锅铲。

## 一 食材准备

| 食材 | 用量 | 选择与用途 |
|---|---:|---|
| 北豆腐 | 500克 | 选质地较结实的老豆腐，切约1厘米厚的片 |
| 大葱 | 150克 | 葱白和浅绿部分约100克先炒，葱绿约50克最后加入 |
| 食用油 | 共20克 | 煎豆腐的全部批次共用15克，炒葱用5克 |
| 生抽 | 15毫升 | 加入料汁 |
| 蚝油 | 10克，可选 | 加入料汁；需要素食口味时可用菌菇素蚝油或省略 |
| 老抽 | 约2—3毫升，可选 | 少量上色 |
| 白糖 | 2克，可选 | 调整料汁风味，不必额外多加 |
| 清水 | 先用150毫升，另备约50毫升开水 | 前者调料汁，后者在烧制时按需补入 |
| 玉米淀粉 | 3克，可选 | 与下方15毫升水调成水淀粉，按需要勾芡 |
| 调水淀粉用水 | 15毫升 | 与料汁用水分开计量 |
| 盐 | 0—1克 | 最后尝味再决定是否添加 |

生抽和蚝油已经带咸味，先不在料汁里加盐。省略蚝油时，最后再按口味调整；喜欢汤汁流动的口感，也可以省略水淀粉。

## 二 详细步骤

### 1 切豆腐并擦干

豆腐沥去包装水，切成约1厘米厚、3—4厘米见方的片。用干净厨房纸轻轻吸去表面水分，不用用力挤压，避免碎裂。

豆腐厚度尽量一致，较薄的片容易碎，较厚的片需要更长烧制时间。大葱洗净擦干，葱白和浅绿部分斜切成约1厘米的段，葱绿另切段，分开放置。

### 2 调好料汁和水淀粉

小碗中加入150毫升清水、15毫升生抽、可选的10克蚝油、老抽和白糖，搅匀。使用水淀粉时，在另一只小碗中把3克淀粉与15毫升水搅匀。

两碗分开放好。水淀粉静置后会沉淀，最后下锅前还要重新搅匀。

### 3 分批煎豆腐

平底锅用中火温热，加入约8克油，摆入一半豆腐，尽量单层铺开。先煎约2—3分钟，底面微黄、边缘定形后再用宽锅铲翻面，另一面也煎约2—3分钟。

煎好的豆腐轻轻盛出。第二批补入剩余约7克煎油，按同样方法煎好。**15克是两批煎豆腐的总油量。**锅内仍有明显油膜时，可少补一点，不必追求厚重的酥壳。

不要刚下锅就反复翻动。时间随锅温和豆腐厚度变化，以表面微黄、能完整铲起为准；上色太快时降低火力。

### 4 降低锅温后炒葱

豆腐全部盛出后，调成中小火。若锅仍很热，可暂时移开炉火稍降温，再加入炒葱用的5克油。

放入葱白和浅绿部分，轻轻翻炒约2—3分钟，至葱香出来、边缘略微发黄。不要一直炒到整体焦黑，避免汤汁发苦。

### 5 加豆腐和料汁烧入味

把煎好的豆腐放回锅中，倒入调好的料汁。尽量铺匀，少量重叠时，用勺子把汤汁淋到上层豆腐上。

煮开后转中小火，保持汤汁轻轻冒泡，盖上锅盖烧约5—6分钟。中途轻轻推动锅底，或用宽锅铲翻动一次，让豆腐两面接触汤汁；不大力翻炒。

汤汁下降太快、锅底将干时，每次补约20—30毫升开水，再继续烧，不必把备用水全部加完。最后1—2分钟加入葱绿，煮到葱绿变软、豆腐内外都热透。

### 6 按需薄勾芡

喜欢薄芡时，先把水淀粉重新搅匀，加入约一半，轻晃锅或用勺子轻推，让芡汁均匀分散。煮开约30秒，再看稠度。

汤汁已经能薄薄挂在豆腐上，就不用加剩余水淀粉；仍明显偏稀时再少量补加并煮开。喜欢清爽汤汁的可跳过这一步，保持锅中还有少量汁水。

### 7 尝味并盛盘

尝一小块豆腐或少量汤汁，再决定是否补少许盐。豆腐热透、葱已熟软、汤汁达到喜欢的稠度，即可关火。

用宽锅铲轻轻移入盘中，把葱和汤汁浇在豆腐上。不要为了把汤完全收干而继续久烧，以免粘锅。

## 三 常见问题

| 问题 | 调整方法 |
|---|---|
| 豆腐碎 | 用质地结实的北豆腐，切约1厘米厚，煎到定形再翻；烧制时轻推而不大力翻炒。 |
| 煎时粘锅、不上色 | 先吸干表面水分，温热锅后放油，豆腐单层分批煎；不要一入锅就铲动。 |
| 葱味苦 | 煎豆腐后先降低锅温，再中小火炒葱，只炒到边缘微黄。 |
| 豆腐里面味淡 | 保留足够汤汁，轻烧5—6分钟，中途让两面接触料汁，盛盘时再浇上汤汁。 |
| 汤汁太稠 | 水淀粉分次添加；已太稠时补少量开水，轻推并重新煮开。 |
| 太咸 | 生抽、蚝油和老抽都带咸味，盐最后尝味再加，先不叠加其他咸味调料。 |

## 四 提前准备与扩量

可以提前切好豆腐和大葱，分别装入干净容器冷藏，煎制前再吸干豆腐表面的水分。料汁也可提前调好冷藏，水淀粉临用重新搅匀。这道菜当天现煎现烧口感更好。

成品需要留到下一顿时，应及时分装冷藏，冰箱保持4°C或以下，熟食一般在做完2小时内放入冰箱；再吃时充分复热，避免反复冷却和加热。[香港食物安全中心 食物存放与复热说明](https://www.cfs.gov.hk/english/consumer_zone/safefood_all/five_keys_reminder.html)

做6人份配餐菜时，可把本配方按4人份计，豆腐用750克、大葱225克、食用油最多约30克、生抽约22毫升、蚝油15克、老抽约3—4毫升、糖3克。清水先用约225毫升，淀粉准备约4.5克、调淀粉用水约22毫升，仍按最终稠度分次添加，盐最后少量调整。

豆腐保持原来的厚度，锅不够大时分更多批煎，烧制时也可分两锅；时间随批次和锅容量调整，不把全部豆腐挤进原锅。
