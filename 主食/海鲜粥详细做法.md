# 海鲜粥详细做法

这份家庭海鲜粥用鲜虾和鱼片搭配，米粒煮到开花，粥底清鲜、略有稠度。**先把白粥煮好，再分批加入海鲜，煮熟后及时关火**，能兼顾米的软糯和海鲜的口感。

- **份量：**约2—3人份。
- **配方基准：**120克生大米，搭配200克去头带壳虾和150克净鱼肉。
- **用时：**大米浸泡约20—30分钟，煮制约40—50分钟；处理海鲜可在煮白粥时完成。
- **锅具：**约3升的厚底汤锅。锅盖留缝，防止溢锅。

## 一 食材准备

| 食材 | 用量 | 选择与用途 |
|---|---:|---|
| 大米 | 120克 | 普通大米即可，喜欢绵软口感可用东北大米 |
| 清水 | 先加1.4升，另备200—300毫升开水 | 备用水按粥的浓稠度添加，不必全部用完 |
| 鲜虾 | 200克 | 按去头带壳重量计；也可换成约150克净虾仁 |
| 鱼肉 | 150克 | 按去骨净肉重量计，可用鲈鱼或鳕鱼，仔细检查鱼刺 |
| 生姜 | 10克 | 切细丝，分两次加入 |
| 小葱 | 1根 | 葱白、葱绿分开切碎 |
| 盐 | 先准备4克 | 最后先加2克，尝味后少量补加，不必全部放完 |
| 白胡椒粉 | 一小撮，约0.2克，可选 | 出锅前加入 |
| 香油 | 几滴，可选 | 盛碗后按口味添加 |

想增加配料，可以另加200克已吐沙的带壳蛤蜊，做法见下方。蛤蜊汤要计入煮粥水量，最后相应减少盐。

## 二 详细步骤

### 1 淘米并浸泡

大米轻轻淘洗两遍，加清水浸泡20—30分钟，再沥去浸泡水。室温较高时放冰箱冷藏浸泡。

### 2 煮白粥底

锅中加入1.4升清水，烧开后放入沥干的大米，搅动锅底，避免米粒粘住。

再次煮开后转小火，保持粥面轻轻冒泡，锅盖留缝，煮约30—40分钟。每隔5—10分钟沿锅底搅拌一次，后半程粥变稠时增加搅拌次数。

**米粒已经开花、没有硬芯，粥汤略稠**，就可以进入下一步。若米还硬而水已经偏少，每次补50—100毫升开水，继续煮软；时间以实际米粒状态为准。

### 3 处理鲜虾和鱼片

煮粥期间处理海鲜：鲜虾去头、去虾线，洗净沥水，可保留虾壳，也可以剥成虾仁。鱼肉检查并去掉残留鱼刺，切成约5毫米厚的片。

冷冻海鲜提前放冰箱冷藏解冻。处理好的虾、鱼片先放回冰箱，等粥底煮好后再取出下锅。处理生海鲜的刀、砧板与盛熟粥的餐具分开使用。[FDA 海鲜处理与烹调指南](https://www.fda.gov/food/buy-store-serve-safe-food/selecting-and-serving-fresh-and-frozen-seafood-safely)

### 4 放姜丝和鲜虾

先检查粥底的浓稠度，偏稠时补少量开水并重新煮开。粥出锅后还会继续吸水，此时保留一点流动性更合适。

粥底煮好后，加入葱白和一半姜丝，调到中小火，让粥保持轻微沸腾。

加入鲜虾，轻轻搅匀。等粥重新冒泡后，先煮约2分钟，再放鱼片；如果虾个头较大，可适当延长这一阶段。

### 5 放鱼片并煮熟

加入鱼片和剩余姜丝，用勺背轻推，让鱼片分散，避免用力搅碎。等粥重新冒泡后，再煮约2—3分钟，并检查海鲜是否熟透。

虾肉应变得不透明、紧实，鱼片中心熟透并能轻轻分成片；**时间只是参考，海鲜大小和下锅后的温度都会影响熟成**。有食物温度计时，可确认最厚处的鱼肉和虾肉中心达到至少63°C。达到熟度后及时关火，避免海鲜久煮变硬。[FDA 海鲜烹调指南](https://www.fda.gov/food/buy-store-serve-safe-food/selecting-and-serving-fresh-and-frozen-seafood-safely)

### 6 调味并盛碗

先加入2克盐，搅匀后尝味，再按需要少量补加。加入白胡椒粉，撒葱绿即可盛碗；喜欢香油的，每碗滴几滴。

## 三 加蛤蜊的做法

1. 另备200克已吐沙的活蛤蜊，刷洗外壳。丢弃破壳的，以及轻敲后仍不能闭合的蛤蜊。
2. 小锅加入约300毫升清水和两片姜，烧开后放入蛤蜊，煮至开壳、肉熟；未开壳的丢弃。[FDA 贝类选择与烹调指南](https://www.fda.gov/food/buy-store-serve-safe-food/selecting-and-serving-fresh-and-frozen-seafood-safely)
3. 捞出熟蛤蜊，可取出蛤蜊肉。煮蛤蜊的汤先静置沉淀，再缓慢倒出上层汤，经细滤网和干净滤布过滤；锅底沉渣不要倒入粥里。
4. 在煮白粥时，用过滤好的蛤蜊汤替代等量清水，总起始水量仍为1.4升。例如用了250毫升蛤蜊汤，就加1.15升清水。
5. 虾和鱼片煮熟前约1分钟，把熟蛤蜊肉放回粥中，一起煮至热透，再尝味加盐。

## 四 常见问题

| 问题 | 调整方法 |
|---|---|
| 海鲜有腥味 | 检查食材是否新鲜、是否妥善冷藏，并确认虾线已去除。姜丝、胡椒只辅助调味；有明显酸臭或氨味的海鲜不要使用。 |
| 虾硬、鱼片柴 | 白粥先煮好，海鲜最后下锅，熟透后及时关火。 |
| 粥太稠 | 补少量开水并重新煮开，关火时保留一点流动性。 |
| 粥太稀 | 下海鲜前先把粥底适当收浓，避免靠延长海鲜的煮制时间来收水。 |
| 粘底或溢锅 | 用厚底锅，小火保持轻微沸腾，锅盖留缝，定时搅拌锅底。 |
| 加了蛤蜊后有沙 | 蛤蜊单独煮，汤先沉淀再过滤，弃去底部沉渣。 |

海鲜粥趁热吃口感最好。留作下一顿的部分应尽快分装到小容器中冷藏，避免整锅长时间放在室温；再吃时边搅拌边充分加热。[香港食物安全中心 熟米饭的处理](https://www.cfs.gov.hk/english/trade_zone/safe_kitchen/Foods_that_need_extra_care.html)
