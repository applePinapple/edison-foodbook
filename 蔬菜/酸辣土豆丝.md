# 酸辣土豆丝

土豆切成粗细均匀的细丝，洗去表面淀粉并短时浸泡，沥干后分批炒熟。醋在土豆基本炒熟后分次加入，酸香明显，也方便按口味调整辣度。

- **份量：**约4人份配餐菜，搭配主食和其他菜一起吃。
- **总用时：**约25—30分钟，包含洗切、5分钟浸泡、沥水和分两批炒制；手切较慢或锅更小时需要延长。
- **实际动手时间：**约20—23分钟，浸泡时可同时准备蒜和调料。
- **器具：**28—30厘米炒锅、锅铲、刀和砧板、清水盆、沥水篮、干净盛菜盘。

## 一 食材准备

| 食材 | 用量 | 选择与用途 |
|---|---:|---|
| 土豆 | 去皮后净重500克 | 切成约2—3毫米的细丝，粗细尽量均匀 |
| 青椒 | 去蒂去籽后80克，可选 | 切细丝，不放时可以直接省略 |
| 大蒜 | 去皮后10克 | 切末或薄片，两批均分 |
| 干辣椒 | 1—2个，可选 | 剪小段，少辣可去籽或省略 |
| 食用油 | 共15克 | 两批各用约7.5克，是全部炒制的总油量 |
| 米醋 | 共15—20毫升 | 每批用一半，接近出锅时分次加入 |
| 生抽 | 共0—5毫升 | 可省略；使用时两批均分 |
| 盐 | 共准备2—3克 | 先用2克，两批各1克，剩余按味道少量补加 |
| 开水 | 另备30—50毫升 | 仅在锅底偏干、土豆尚未熟时少量补入，不必全部使用 |
| 清水 | 洗土豆丝与浸泡所需，能浸没即可 | 洗泡后倒掉，不加入成品 |

**浸泡只用清水，不要先拌醋腌土豆丝。**提前加醋会让土豆丝更难炒软；这份做法等土豆基本炒熟再调酸味。

## 二 详细步骤

### 1 洗切土豆和青椒

土豆洗净去皮，称取500克，先切约2—3毫米薄片，再切成同样粗细的丝。尽量让土豆丝粗细一致；发现明显粗条时补切细一些。青椒洗净后去蒂去籽，切细丝。

### 2 清洗浸泡后充分沥水

土豆丝用流动清水冲洗并轻轻拨散，洗去表面明显淀粉，再放入清水盆浸泡5分钟。浸泡时切好蒜、辣椒并量好调料。泡好后倒掉水，将土豆丝放入沥水篮充分沥干，不要带着一盆水下锅。

### 3 分批并炒香配料

把土豆丝分成两份，每份约250克；青椒、蒜和辣椒也均分。盐先分出两份各1克，剩余备用；油、生抽和米醋均分到两批。

锅用中火温热，加入第一批约7.5克油，调成中小火。先放可选的干辣椒炒约10—20秒，再放一半蒜炒约10—20秒，闻到香味后立即转中大火加入土豆丝，避免蒜和辣椒在空锅中焦黑。

### 4 炒熟第一批土豆丝

不断翻炒、拨散土豆丝，约1—2分钟后加入第一批青椒丝和1克盐，继续炒约2—3分钟。每批炒制通常约需4—5分钟，以实际粗细和锅温为准。

夹一根较粗的土豆丝，略放凉后检查：应能咬断、没有明显生硬芯或生土豆味，同时仍保留一些脆感。土豆尚未熟、锅底却偏干时，每次沿锅边补约10毫升开水，翻匀后继续炒熟；不要靠继续大火干烧来完成熟度。

### 5 接近出锅时分次加醋

土豆丝基本炒熟后，加入第一批的可选生抽，翻匀。把分给这一批的米醋分两次加入：先加一半，翻匀尝味，再加剩余部分或按口味少量保留。最后翻炒约20—30秒，盛出。需要更咸时，再从备用盐中少量补加。

加醋后不必久炒；土豆仍有生硬芯时，先继续炒熟，再用醋调味。

### 6 炒第二批并盛盘

锅转回中小火，必要时离火稍降温，加入第二批约7.5克油、蒜和辣椒。按同样顺序炒剩余土豆丝、青椒和1克盐，确认炒熟后再加入第二批生抽、分次加醋。

两批合放到干净盛菜盘中，轻轻拌匀，趁热吃。总油量为15克、总盐量为2—3克，第二批只使用已分好的剩余调料。

## 三 常见问题

| 问题 | 调整方法 |
|---|---|
| 土豆丝粘连、锅底发糊 | 切后洗去表面淀粉，充分沥干；分批拨散炒，锅底干而未熟时少量补开水 |
| 有的熟了、有的还硬 | 土豆丝切成均匀的2—3毫米，粗条补切；夹较粗的一根检查熟度 |
| 加醋后一直炒不软 | 不在洗泡阶段加醋；先炒到无明显生硬芯，最后再分次调醋 |
| 口感软塌、酸味变淡 | 达到熟度后及时调味盛出，避免在加醋后持续久炒或长时间焖盖 |
| 一锅菜水多、翻不动 | 沥干洗泡水，用小份分批炒；青椒也分到各批，不一次全部下锅 |
| 辣度太高 | 干辣椒减量、去籽或省略；青椒选不辣的甜椒类品种，并按实际口味选择 |

## 四 提前准备与扩量

可以提前称好干调料、切好蒜和青椒，分别按适当方式保存；土豆丝尽量当天现切现洗，再按步骤短泡和沥干。现炒口感更好，制作和存放细节见[蔬菜制作与存放说明](README.md#卫生与存放)。

做6人份配餐菜时，土豆去皮净重750克、青椒净重120克或省略、蒜15克、干辣椒约2—3个或省略、油共22.5克、米醋共22.5—30毫升、生抽共0—7.5毫升、盐共3—4.5克，另备约50—75毫升开水按需使用。

用同一口28—30厘米锅分成3批，每批仍约250克土豆丝、40克青椒、5克蒜和7.5克油；调料均分，盐先每批用1克，再按味道补加。清水浸泡仍为5分钟，每批炒制按原来的熟度判断，总用时约35—40分钟；增加的是切配和批次数，不把每批炒制时间直接加倍。
