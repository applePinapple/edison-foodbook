# 家庭蔬菜菜谱

这组菜谱使用常见蔬菜和普通锅具，每份约4人份配餐菜。食材用量按去根、去皮或去掉老叶后的净重计算，辣椒可以按口味减少或省略。

## 菜谱选择

| 菜谱 | 总用时 | 主要食材 | 烹饪要点 |
|---|---|---|---|
| [蒜蓉西兰花](蒜蓉西兰花.md) | 20—25分钟 | 西兰花、蒜，可加胡萝卜 | 梗切薄，焯水后沥干再炒 |
| [香菇炒油菜](香菇炒油菜.md) | 20—25分钟 | 鲜香菇、油菜 | 香菇先炒熟，菜梗先于菜叶下锅 |
| [手撕包菜](手撕包菜.md) | 20—25分钟 | 包菜、蒜，可加干辣椒 | 洗后沥干，厚梗切薄，锅小分批炒 |
| [酸辣土豆丝](酸辣土豆丝.md) | 25—30分钟 | 土豆、蒜，可加青椒与干辣椒 | 丝切均匀，洗去表面淀粉，炒熟后加醋 |
| [清炒西葫芦](清炒西葫芦.md) | 15—20分钟；小锅分批20—25分钟 | 西葫芦、蒜 | 切均匀薄片，盐后放，不久焖 |
| [番茄烧茄子](番茄烧茄子.md) | 30—35分钟 | 番茄、茄子、蒜 | 番茄炒出汁，加水焖到茄子熟软 |

上表包含当天洗切、烧水及菜谱注明的全部批次。锅具、火力和切块大小会影响实际用时，结束烹调时还要检查菜谱注明的熟度。

想吃清爽的炒菜，可以选西兰花、油菜或西葫芦；喜欢酸辣口味，可以选包菜或土豆丝；想要软嫩、带汤汁的口感，可以选番茄烧茄子。

## 份量与火候

- 做6人份时，食材基本用量乘1.5；做8人份时乘2。各菜谱附有6人份用量，盐和咸味调料先少放，尝味后再补。
- 蔬菜太多会让锅温下降、出水增多。锅不够大时分批炒，油和调料按批次分配，总量不重复添加；预计用时也要留出额外批次。
- 蒜和干辣椒先用中小火炒香，再调整火力炒菜；不把锅内调料炒焦后继续做。
- 叶菜、瓜片与茄子的熟度判断不同，按各菜谱检查菜梗、片厚或块心，不只看颜色。焖煮和翻炒时间不按人数机械加倍。

## 卫生与存放

洗手并清洗刀、砧板和锅具。蔬菜用流动清水洗净，叶菜逐片清洗，去掉老叶和损坏部分；需要去皮的蔬菜也先清洗。蔬菜和可以直接吃的食物，与生肉、生鱼的器具分开使用。[FoodSafety.gov 食材清洗与分开处理说明](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety)

可以提前洗切备料，沥去多余水分后分别装入干净容器及时冷藏，炒制前再取出。土豆丝洗后短时泡水按菜谱进行，不留在常温水中泡一整夜；蒜末和干辣椒可临下锅前准备。

成菜现做口感较好。需要留到下一顿时，分装到浅容器中尽快冷藏，不等整锅在室温下彻底放凉。冰箱保持4°C或以下，易腐食物应在2小时内冷藏，环境高于32°C时缩短到1小时内。[FoodSafety.gov 熟食冷藏说明](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety)

再次食用时取出需要的份量充分复热，翻动或搅拌，让中心也热透；有温度计时，熟食复热中心达到至少74°C。叶菜和瓜片复热后会更软，避免整份反复冷却和加热。[FoodSafety.gov 熟食复热温度](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)
