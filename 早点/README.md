# 家庭早餐菜谱

这组早餐按约4人份安排，适合一次做够一家人吃。用普通锅具和常见食材，搭配谷薯类主食、蛋白质食物和蔬菜；菜谱中列出的牛奶、酸奶、豆浆或小番茄也属于整套早餐的用量。

搭配参考了[中国疾控中心关于早餐食物种类的建议](https://www.chinacdc.cn/jkkp/yyjk/swyy/202512/t20251231_314379.html)。这些菜谱用于丰富早餐选择，全天仍应轮换不同食材，按各人的食量调整份量。

## 菜谱选择

| 菜谱 | 总用时 | 实际动手 | 主食 | 蛋白质食物 | 蔬菜 |
|---|---|---|---|---|---|
| [南瓜牛奶燕麦粥配鸡蛋](南瓜牛奶燕麦粥配鸡蛋.md) | 25—30分钟 | 约12分钟 | 燕麦 | 牛奶、鸡蛋 | 南瓜、小番茄 |
| [全麦鸡蛋蔬菜三明治](全麦鸡蛋蔬菜三明治.md) | 约25分钟 | 约15分钟 | 全麦面包 | 鸡蛋、无糖酸奶 | 黄瓜、番茄 |
| [蔬菜鸡蛋饼](蔬菜鸡蛋饼.md) | 单锅45—55分钟 | 30—40分钟 | 面粉 | 鸡蛋、牛奶或无糖熟豆浆 | 西葫芦、胡萝卜 |
| [番茄鸡蛋豆腐面](番茄鸡蛋豆腐面.md) | 25—30分钟 | 12—15分钟 | 面条 | 鸡蛋、豆腐 | 番茄、青菜 |
| [电饭锅鸡肉蔬菜饭](电饭锅鸡肉蔬菜饭.md) | 50—60分钟 | 约15分钟 | 大米、土豆 | 鸡肉 | 胡萝卜、蘑菇、豌豆 |
| [红薯玉米蒸盘配豆腐蒸蛋](红薯玉米蒸盘配豆腐蒸蛋.md) | 40—45分钟 | 约15分钟 | 红薯、玉米 | 鸡蛋、豆腐 | 西兰花 |

上表按4人份、当天从头做估算，包含烧水和所有批次。前晚煮好鸡蛋后，三明治早晨约10—15分钟可完成；两口锅同时煎饼约30—35分钟，前晚蒸熟主食的蒸盘早晨约25—30分钟。电饭锅的具体程序时间按机器说明调整。

早晨时间紧时，优先选提前煮好鸡蛋的三明治，或前晚做好、早晨复热的鸡肉蔬菜饭。想当天从头做，燕麦粥和番茄豆腐面更容易集中完成。鸡蛋饼需要分批煎，蒸盘要等主食和蒸蛋熟透，留出菜谱注明的完整用时。

## 份量与扩量

- 每份菜谱默认约4人份，食量较大时优先增加主食，搭配的蛋白质食物和蔬菜也相应增加。
- 做6人份时，固体食材及配餐饮品乘1.5；做8人份时乘2。盐先少放、尝味再补，煮粥和焖饭的水量按食材与锅具调整。
- 使用够大的锅。煎饼、蒸蛋或米饭超出锅具容量时分批做，不能只把火开大；加量后的熟度照样要检查，时间不直接按人数相乘。
- 燕麦选菜谱指定的即食或快熟类型，全麦面包、酸奶与豆浆按包装成分挑选；豆浆使用已经煮熟的成品。

## 提前准备与存放

前一晚可以称好米、燕麦、面粉，洗切蔬菜并分装冷藏，煮熟鸡蛋。鸡肉单独放在密闭容器中冷藏，与可以直接吃的食物分开；早晨取出后再装锅烹调。

准备留到下一顿的熟饭、粥、蛋饼和蒸蛋，应及时分装到浅容器中，尽快放入4°C或以下的冰箱，不要等整锅在室温下彻底放凉。易腐食物一般应在2小时内冷藏，环境高于32°C时缩短到1小时内。[FoodSafety.gov 食物冷藏说明](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety)

前晚做好的早餐可在次晨取出所需份量充分复热。米饭、粥和蒸蛋的中心也要热透，微波加热时中途翻动或搅拌；有温度计时，复热食品中心达到至少74°C。[FoodSafety.gov 熟食复热温度](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)

鸡肉、牛奶、蛋液等需要冷藏的食材，前晚先放冰箱，早晨再煮。用普通电饭锅做鸡肉蔬菜饭时，不把生鸡肉装入锅中常温预约一整夜。
