# 罗宋汤详细做法

这份罗宋汤采用番茄牛肉家庭版，用牛腩、番茄、土豆、胡萝卜、洋葱和卷心菜炖成一锅。**先炖软牛肉，再分批加入蔬菜，最后调咸淡和酸甜**，能让汤味浓郁，同时保留土豆和蔬菜的形状。

- **份量：**约4人份大碗汤，作为配餐汤可分成6份；搭配米饭或面包食用。
- **配方基准：**500克净牛腩，其余蔬菜按处理后的净重计。
- **总用时：**约2—3小时，其中实际动手约30—40分钟；牛肉软烂所需时间会有差别。
- **锅具：**5—6升的厚底汤锅；焯水后把锅洗净，可继续用同一口锅烹煮。

## 一 食材准备

| 食材 | 用量 | 选择与用途 |
|---|---:|---|
| 牛腩 | 500克 | 选适合炖煮、略带筋的部位，修掉厚重外层肥油 |
| 番茄 | 600克 | 选成熟番茄，切小块；去皮可选 |
| 土豆 | 300克 | 去皮后净重，切约2厘米的小块 |
| 胡萝卜 | 200克 | 去皮后净重，切约1—1.5厘米的小块 |
| 洋葱 | 150克 | 切小块 |
| 卷心菜 | 300克 | 去掉硬芯，切约3厘米的片 |
| 西芹 | 100克，可选 | 去老筋，切约1厘米的小段，与卷心菜同放 |
| 无糖浓缩番茄膏 | 30克，可选 | 增加汤底风味；没有时可省略 |
| 食用油 | 共15克 | 用于炒洋葱和番茄 |
| 清水 | 先加1.5升，另备300—500毫升开水 | 备用水按蒸发情况补入，不必全部用完；焯水另计 |
| 盐 | 先准备6克 | 最后先加4克，尝味后少量补加，不必全部放完 |
| 白糖 | 0—5克，可选 | 番茄明显偏酸时，少量平衡酸味 |
| 黑胡椒粉 | 一小撮，约0.5克，可选 | 出锅前调味 |
| 香叶 | 1片，可选 | 与牛肉同炖，出锅前捞出 |

番茄膏与酸甜番茄沙司的浓度、糖和盐含量不同。若用酸甜番茄沙司替代，先放少量，最后尝味再决定是否补糖和盐。

## 二 详细步骤

### 1 切牛肉并准备蔬菜

牛腩修掉多余肥油，切成约2—3厘米的块。洋葱和番茄先切好；胡萝卜、卷心菜等也可在牛肉炖煮期间处理。

土豆去皮切块后若暂时不下锅，可浸在清水中；等待较久时放冰箱冷藏，下锅前沥干。其他切好的蔬菜也先冷藏，等需要时再取出。

### 2 冷水下锅焯牛肉

牛肉放进锅里，加冷水没过食材，开盖加热。浮沫出现后及时撇掉，**从水沸腾后计时，继续焯约3—5分钟**。

捞出牛肉，用温水冲去附着的浮沫。倒掉焯水，把锅内沉渣洗净，再开始炒汤底。

### 3 炒出番茄汤底

洗净的汤锅擦干，用中火加热，加入全部15克食用油。放入洋葱，炒约3—5分钟，至略透明、散发香味。

加入番茄块，炒约5—8分钟，用锅铲轻压，炒到番茄变软、明显出汁。加入可选的番茄膏，再炒约30—60秒，保持锅底湿润，避免番茄膏炒焦。

### 4 先把牛肉炖至接近软烂

放入焯好的牛肉，加入1.5升清水和可选的香叶，搅匀后大火烧开。撇去新出现的浮沫，转小火，半盖锅盖，保持汤面轻轻冒泡。

先炖约60—90分钟，期间偶尔轻推锅底，防止番茄粘底。液体下降太多时，每次补100—150毫升开水，让牛肉保持浸在汤中，锅内留出沸腾空间。

从炖满60分钟开始检查：筷子能插进牛肉，咬起来已经明显变软、仅有少许韧度，就可以加蔬菜。**如果牛肉仍硬，先每次延长15—20分钟再检查，不急着放土豆。**

### 5 加土豆和胡萝卜

放入沥干的土豆块和胡萝卜，轻轻拌匀。重新煮开后转小火，继续炖约15—20分钟，检查土豆的软度。

土豆能被筷子插入、中心仅剩一点阻力时，再进入下一步。如果还明显发硬，延长几分钟再检查。番茄的酸度、土豆品种和块的大小都会影响煮软时间，以实际状态为准。

### 6 最后加卷心菜

卷心菜分两三次加入，稍微煮软一部分再放下一部分，避免锅内太满。放入可选的西芹，重新煮开后再炖约8—10分钟。

此时土豆从下锅起通常共炖约25—30分钟，具体以软熟为准。土豆和胡萝卜应能轻松戳透，牛肉软烂，卷心菜梗也已变软。若某一种食材还硬，再短时续煮；搅拌时轻推，避免把土豆搅碎。

### 7 最后调味并盛碗

先加入4克盐，搅匀尝味，再按需要少量补加。番茄已充分煮熟后仍明显偏酸时，可先加2克糖，再尝味决定是否追加；成熟番茄可能无需加糖。长时间炖煮并不能保证酸味消失。

加入可选的黑胡椒，捞出香叶。汤太稠时补少量开水并重新煮开；太稀时可以开盖短时收浓，再复查咸淡。盛碗时把牛肉和蔬菜均匀分给每个人。

## 三 常见问题

| 问题 | 调整方法 |
|---|---|
| 牛肉仍硬 | 牛腩的筋需要时间炖软，先延长牛肉的炖煮阶段，接近软烂后再加土豆。 |
| 土豆碎、卷心菜烂 | 蔬菜后放，保持轻微沸腾；土豆煮到接近软熟才放卷心菜，避免大力搅拌。 |
| 汤太酸 | 用成熟番茄，先充分炒软和煮熟，最后少量加糖平衡酸味。用番茄沙司时先尝味再补糖。 |
| 汤味偏淡 | 确认番茄已炒出汁；汤太稀时适当收浓，之后再调整盐。 |
| 汤底发苦或粘锅 | 炒番茄膏时保持锅底湿润，炖煮时偶尔轻推锅底，水少及时补。已经明显焦苦时，不把锅底焦层刮进汤里。 |

## 四 提前准备与扩量

可以前晚把汤做好，及时分装到浅容器中冷藏，避免整锅长时间留在室温。易腐熟食一般应在2小时内冷藏，环境高于32°C时缩短到1小时内，冰箱保持4°C或以下。[FoodSafety.gov 熟食冷藏说明](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety)

再吃时取出需要的份量，边搅拌边充分加热，确认牛肉和土豆中心也热透；有温度计时，复热食品中心达到至少74°C。复热时轻轻推动，避免土豆碎成泥。[FoodSafety.gov 熟食复热温度](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)

如果要做6人份大碗汤，固体食材乘1.5，牛肉用750克、番茄900克、土豆450克、胡萝卜300克、洋葱225克、卷心菜450克，其他配料相应调整。清水先加约2.25升，再按锅内液体量补充；换用约8升汤锅，牛肉仍切成相同大小。加量后的烧开时间会变长，炖煮时间仍以软烂程度判断，不直接乘1.5。
