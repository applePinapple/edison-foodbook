# 藏书羊肉汤详细做法（500克羊肉家庭版）

藏书羊肉汤在家做，重点是**羊肉连骨熬汤、调味清淡、先滚煮再慢炖，最后撒青蒜叶**。传统藏书羊肉用杉木“盆堂”烧煮，讲究汤浓、肉酥；羊汤还常搭配白菜、粉丝、油豆腐等。相关介绍可参考[苏州文旅：苏州特色羊肉美食寻鲜地图](https://visitsz.wglj.suzhou.com.cn/news-detail.aspx?id=1053)。

以下是适合家庭厨房的白汤做法，用普通汤锅调整操作，不能完全复制传统木桶的风味，但能做出鲜香的羊肉汤。

- **配方基准：**500克净羊肉，不含另外搭配的羊骨重量。
- **份量：**约2—3人份。
- **用时：**浸泡约1小时，正式烧煮约2—3小时；羊肉老嫩不同，时间会有差别。羊肉用量减半，炖煮时间不用减半，仍以肉质软嫩为准。
- **锅具：**约4升的厚底汤锅，水量以没过食材、煮沸时不溢锅为准。

**去膻的核心是修掉多余羊油，再冷水下锅焯水、撇净浮沫，洗净肉和锅后换水炖。** 羊膻味与脂肪中的风味物质有关；浸泡、焯水主要减少血腥味和杂味，不能完全去掉羊肉自身的风味。下方步骤已包含这些处理。

## 一、食材准备

| 食材 | 用量 | 选择与用途 |
|---|---:|---|
| 羊肉 | 500克 | 优先选山羊腿肉或肩肉，修掉厚重外层脂肪，保留少量肥肉；带皮的口感更软糯 |
| 羊骨 | 250克 | 羊筒骨或脊骨，让摊主敲开或剁段 |
| 清水 | 约1.75升 | 熬汤用，以没过食材为准；浸泡、焯水另计 |
| 生姜 | 1—2片，可选 | 放在焯水阶段辅助去味，焯水结束后丢弃 |
| 青蒜 | 1—2根 | 蒜白、蒜叶分开切碎 |
| 盐 | 先准备5克 | 按最终汤量，每升先放约3克，再尝味补盐，不必全部用完 |
| 白胡椒粉 | 一小撮，约0.2克，可选 | 吃的时候加在碗里 |
| 羊油 | 10—15克，可选 | 肉和骨头都很瘦、想让汤更浓时再加；已有肥肉或想减轻膻味时不用额外加 |

这版白汤不用放料酒、八角、桂皮或酱油，保留羊肉本身的鲜味。

想做成羊肉汤锅，可以另外准备以下配菜，等原汤熬好后再放：

| 配菜 | 用量 |
|---|---:|
| 白菜 | 150克 |
| 油豆腐 | 50克 |
| 干粉丝 | 25—40克 |

## 二、详细步骤

### 1. 修掉多余脂肪，切块浸泡

先修掉羊肉厚厚的外层羊油，保留少量肥肉。羊油本身气味较重时，熬汤也不用额外加羊油。

将500克羊肉切成2—3大块，不要一开始就切薄片或小丁。检查250克羊骨，去掉松散的碎骨渣。

羊肉、羊骨放入冷水中，水量没过食材，浸泡约1小时，中间换水2次；天气热时放冰箱冷藏浸泡。泡好后沥水。

### 2. 冷水下锅，开盖焯水并撇净浮沫

羊肉、羊骨放进锅里，重新加冷水没过食材，可放入1—2片姜，开盖加热。**浮沫一出现就撇掉**，水开后继续煮约5分钟，直到大量浮沫不再涌出。

捞出肉和骨头，用温水洗掉附着的浮沫。焯水和姜片丢弃，把锅底的沉渣也洗干净，再开始熬汤。这里采用家庭容易掌握的“焯水后换水”方法。

### 3. 重新加水，开始熬汤

将羊骨放在洗净的锅底，羊肉放在上面，加入约1.75升新清水，以没过食材为准。肉和骨头都很瘦、想让汤更浓时，可加10—15克羊油；想减轻膻味就不额外加。

开盖大火烧开，再撇掉新出现的灰褐色浮沫。此时先不加盐。

### 4. 中大火滚煮25—30分钟

调整火力，让汤面保持明显翻滚，同时避免溢锅。锅盖敞开或留较大缝隙。这个阶段能让汤逐渐变浓、颜色变浅。

撇去脏浮沫，留一点脂肪更容易熬出白汤。如果更在意味道清淡，可以适量多撇一些油，汤色不必追求乳白。

### 5. 转中小火，煮到羊肉软嫩

改成汤面持续轻轻冒泡的火力，半盖锅盖，再煮约60—90分钟。中途翻动羊肉一两次，防止贴底。

水位下降太多时，补少量开水，让肉保持浸在汤里。

从这一阶段煮满60分钟开始检查：**筷子能较轻松插进肉块厚处，夹起时肉仍完整**，就可以捞出。若还明显发硬，每次延长15—20分钟再检查，以实际软嫩程度为准。

### 6. 肉先捞出，骨头继续熬汤

羊肉煮好后放入容器，浇一点原汤并盖住，避免表面风干。

锅里的羊骨继续煮30—45分钟；想让汤更浓，可以用中火保持翻滚。如果汤已经浓鲜，就不必继续收浓。家庭羊汤呈乳白或浅米白都正常，不必为了颜色一直熬。

### 7. 过滤汤底，最后调咸淡

捞出骨头，用细滤网过滤汤里的骨渣。

按最终汤量加盐：每升成汤先加约3克盐，例如剩下1.2升汤，先加约3.6克盐，搅匀尝味后再少量补加。准备的5克盐不必全部放完。表面如果积了一层厚油，可以适量撇掉。

### 8. 羊肉切片，回汤加热

羊肉稍微晾到不烫手，逆着肉的纹理切成约4—5毫米厚的片；带骨的先剔骨。

将当天要吃的肉放回热汤，轻轻煮开1—2分钟即可，避免久煮散碎。

### 9. 撒青蒜，盛碗上桌

青蒜白可以先放汤里煮约半分钟，青蒜叶在关火前撒入，也可以直接放在碗底再浇热汤。

白胡椒粉按个人口味加少许。喜欢辣味的，另外配辣椒酱蘸羊肉。

## 三、白菜粉丝羊肉锅做法

原汤熬好后，可以接着做成羊肉汤锅：

1. 另外取一口锅，放入熬好的羊汤和切好的油豆腐，煮3—5分钟。
2. 加入白菜梗，煮约3分钟。
3. 放入白菜叶、按包装说明泡好的粉丝和熟羊肉片，煮至粉丝软透、食材热透。
4. 最后尝味补盐，撒青蒜叶即可。

## 四、常见问题

| 问题 | 调整方法 |
|---|---|
| 膻味偏重 | 检查是否保留了过多外层羊油、焯水时是否撇净浮沫，以及肉和锅底沉渣是否洗净。少量姜片只能辅助去味；浸泡、焯水不能完全去掉羊肉自身的风味。 |
| 汤淡 | 通常是水偏多。先捞出熟肉，再让骨汤适当收浓，最后调盐。 |
| 肉柴 | 优先用略带肥肉的肩肉或腿肉；煮软后及时捞出，切片后只需短时间回热。 |
| 汤不够白 | 检查是否全用瘦肉、全程火力太小。保留适量羊油并安排一段滚煮，比单纯延长小火炖煮更有效；想减轻膻味时，不必为了汤白额外加油。 |
